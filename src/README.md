# Исходный код

- `App.cs` — интерфейс Windows Forms.
- `Theme.cs` — оформление карточек, кнопок и индикатора выполнения.
- `Core.cs` — сбор файлов, контрольные суммы и адаптеры MLT/Kdenlive.
- `OpenShot.cs` — адаптер проектов OpenShot.
- `PopularEditors.cs` — экспериментальный сбор ссылок Adobe/XML.
- `Tests.cs`, `PopularTests.cs` — проверки движка и адаптеров.

Сборка и тесты запускаются из корня репозитория: `build.ps1`, `test.ps1`.

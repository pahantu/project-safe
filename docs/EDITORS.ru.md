# Поддержка в версии 0.5

В 0.5 обновлён интерфейс; возможности адаптеров соответствуют 0.4. Регрессионные проверки проходят.

| Редактор / формат | Что делает Сейф | Проверка в редакторе |
|---|---|---|
| Shotcut, основные MLT-ссылки | Сбор медиа и отдельный Ready с относительными ссылками | В 0.3 проверены открытие и совпадение экспорта; в 0.4 прошла регрессия кода |
| Kdenlive, документ 1.1 | Основные медиа, прокси, оригиналы; Ready для поддержанных проектов | Нативная проверка выполнена в 0.3; в 0.4 прошла регрессия кода |
| OpenShot 4.1.x | Основные медиа и поддержанные ресурсы; Ready | Нативная проверка выполнена в 0.3; в 0.4 прошла регрессия кода |
| Premiere Pro .prproj | Экспериментальное чтение известных XML-полей, включая gzip; сбор доступных файлов | **Нет.** Полнота и открытие в Premiere не подтверждены. Ручная перепривязка |
| After Effects .aepx | Сбор доступных `fileReference/@fullpath` | **Нет.** Ручная перепривязка; серии кадров требуют Collect Files |
| After Effects .aep / .aet | Сохранение оригинала; сбор через созданную редактором выгрузку .psdeps | **Нет.** Скрипт проверен на модели API, не внутри Adobe |
| Final Cut Pro .fcpxml | Сбор доступных оригиналов и прокси из `asset` / `media-rep` | **Нет.** Библиотеки FCP не разобраны, импорт/перепривязка вручную |
| Premiere / Resolve, обменный Final Cut XML | Сбор ссылок `file/pathurl` в XML с корнем xmeml | **Нет.** Не заменяет нативный проект и не гарантирует сохранение эффектов |
| Resolve .drp | Точная копия и инструкция по Project Archive / обменному XML | **Нет.** Связи внутри DRP не разбираются |
| VEGAS, CapCut и остальные закрытые форматы | Точная копия файлов выбранной папки с предупреждением | Поддержка связей не реализована |

Ни один новый адаптер Adobe/XML не создаёт Ready. Обнаружение путей — не подтверждение
полноты зависимостей. Отсутствие сообщения о пропавшем файле не означает, что собраны все эффекты.
В бинарных проектах After Effects автоматически читать строки/искать пути не пытаемся.

## Основания и документация

- [Adobe: Project Manager в Premiere](https://helpx.adobe.com/ca/premiere/desktop/organize-media/create-projects/copy-project.html)
- [Apple: FCPXML media-rep](https://developer.apple.com/documentation/professional-video-applications/media-rep)
- [Apple: FCPXML](https://developer.apple.com/documentation/professional-video-applications/fcpxml)

PRPROJ — внутренний формат Adobe. Поддержка чтения известных полей экспериментальная,
схема не считается стабильным публичным контрактом. Изменение этого формата в стороннем
приложении не выполняется. Перед производственным использованием нужны реальные проекты
поддерживаемых версий Adobe и проверка переноса/рендера в самих редакторах.

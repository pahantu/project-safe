СЕЙФ ПРОЕКТА 0.5

1. Закрой редактор или сохрани все правки перед проверкой.
2. Запусти «Сейф проекта.exe», выбери папку проекта и место для отдельной копии.
3. Нажми «Проверить проект» и прочитай вкладку «Что проверить».
4. Нажми «Сохранить копию». Переноси всю полученную папку целиком.

Shotcut / Kdenlive / OpenShot
Для поддержанных вариантов отдельный проект с обновлёнными ссылками появится
в Ready. Оригиналы всегда лежат в Project. Неподдержанные возможности перечислены
в замечаниях. Версии и ограничения смотри в «Поддержка редакторов.md».

Premiere Pro
Положи .prproj в папку проекта. Сейф прочитает известные поля ссылок в XML/gzip
и добавит доступные внешние файлы. Это экспериментальный сбор, не полная проверка
всех вариантов PRPROJ. Project Manager в Premiere остаётся способом проверить
и собрать исходный проект средствами Adobe. Dynamic Link требует отдельного
сбора проекта After Effects и его исходников.

After Effects
Для обычного .aep нужен список зависимостей из самого редактора:
1. Сохрани проект в After Effects.
2. File > Scripts > Run Script File: выбери
   Adobe/Export-AfterEffects-Dependencies.jsx из этой поставки.
3. Сохрани список .psdeps рядом с проектом.
4. Проверь эту папку в Сейфе: добавятся исходный проект, footage и прокси,
   перечисленные в выгрузке. После правок проекта повтори выгрузку.
Скрипт требует разрешённой записи файлов средствами скриптов After Effects.
Если редактор запрещает запись, используй штатный Collect Files.
Если уже есть .aepx, Сейф может собрать доступные fileReference без скрипта.
Серии кадров экспортируй через Collect Files: в списке может быть только первый кадр.
Выгрузка и её работа в реальном Adobe на этом ПК пока не проверены.

Final Cut Pro / DaVinci Resolve / Premiere XML
Читаются .fcpxml (asset/media-rep) и обменные .xml с корнем xmeml (file/pathurl).
Пути с macOS не преобразуются в выдуманные Windows-пути: требуется сбор на исходном
компьютере или ручная перепривязка. XML — обменный документ и может не включать
все возможности оригинального монтажа. Библиотеки Final Cut и .drp Resolve не разбираются.
Для Resolve можно сначала создать Project Archive с медиа в самом редакторе.

ОТКРЫТИЕ ADOBE И ОБМЕННЫХ XML ПОСЛЕ ПЕРЕНОСА
Автоматическая перезапись этих проектов отключена, Ready для них не создаётся.
Открой копию оригинального проекта из Project. В окне поиска отсутствующих медиа
укажи собранные файлы в Project/_linked. «Карта исходников.tsv» сопоставляет старые
пути и новые файлы, включая одинаковые имена из разных папок.
Проверяй каждый путь, если редактор автоматически сопоставляет одинаковые имена.
Сохраняй перепривязанный проект как новую копию средствами редактора.

Кнопка «Проверить готовую копию» подтверждает целостность файлов из manifest.json,
но не подтверждает, что монтаж полностью открывается или выглядит одинаково.
Не удаляй исходники до проверки монтажа в редакторе!
Шрифты, плагины, выражения с внешними файлами, шаблоны, библиотеки облачных
ресурсов и все варианты последовательностей автоматически не собираются.
Программа не загружает файлы в интернет и не обращается к сетевым ресурсам проектов.
